    Thymeleaf

    ¿Qué es Thymeleaf?

    Thymeleaf es un motor de plantillas moderno y flexible utilizado principalmente en aplicaciones web basadas en Java. Permite combinar HTML estático con lógica dinámica para generar páginas web que se adaptan a los datos proporcionados por el servidor.

    Características principales

    Integración con Spring

    Es ampliamente utilizado en aplicaciones Spring Boot debido a su facilidad de uso y compatibilidad.

    Lógica en el Frontend

    Permite insertar datos dinámicos, realizar bucles, condicionales y más directamente en el HTML.

    Reutilización de Código

    Facilita la creación de fragmentos reutilizables (por ejemplo, encabezados y pies de página).

    ¿Cómo funciona Thymeleaf?

    Thymeleaf procesa archivos HTML con atributos especiales llamados atributos Thymeleaf . Estos atributos permiten insertar datos dinámicos desde el backend (controlador) en la vista (HTML). Una vez procesada la plantilla, el resultado es un archivo HTML estático que el navegador puede renderizar.

    Configuración de Thymeleaf en un proyecto Spring Boot

    1. Crear un proyecto Spring Boot

    Puedes crear un proyecto Spring Boot utilizando Spring Initializr.

    Selecciona las dependencias necesarias: Spring Web, Thymeleaf y cualquier otra que puedas necesitar.

    3. Configuración de Thymeleaf

    Spring Boot configura automáticamente Thymeleaf si detecta la dependencia en el pom.xml o build.gradle

    Las plantillas de Thymeleaf se colocan en la carpeta src/main/resources/templates

    4. Crear una plantilla Thymeleaf

    Inicialmente en la carpeta src/main/resources/templates, crea un archivo llamado index.html. Este archivo será tu plantilla Thymeleaf.

    A continuacion se ilustra como implementar el codigo HTML asociando el Thymeleaf

    <!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<head>
    <meta charset="UTF-8">
    <title>Bienvenido a Thymeleaf</title>
</head>
<body>
    <h1 th:text="${mensaje}">Mensaje por defecto</h1>
</body>
</html>

    xmlns:th="http://www.thymeleaf.org" Define el espacio de nombres de Thymeleaf.

    th:text="${mensaje}" Este atributo de Thymeleaf reemplaza el contenido del elemento con el valor de la variable mensaje que se pasa desde el controlador.

    5. Crear un controlador Spring MVC

    En la carpeta src/main/java/com/ejemplo/demo, crea una clase llamada ControladorEjemplo.

    package com.ejemplo.demo;

import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;

@Controller
public class ControladorEjemplo {

    @GetMapping("/")
    public String mostrarMensaje(Model model) {
        model.addAttribute("mensaje", "¡Hola, Thymeleaf!");
        return "index";
    }
}

    @Controller Indica que esta clase es un controlador Spring MVC.

    @GetMapping("/") Mapea la ruta raíz (/) a este método.

    model.addAttribute("mensaje", "¡Hola, Thymeleaf!");: Añade un atributo al modelo que será accesible en la plantilla Thymeleaf.

    return "index";: Devuelve el nombre de la plantilla Thymeleaf (index.html) que se debe renderizar.
